# 개발 우선순위
- P0: 1~2장 진행 불가, 전투 정지, 저장 오류, 카드 효과 불일치 재현 및 수정. 기준 커밋 기록.
- P1: 기존 훈련장 확장. 적/카드/장비/레벨/숙련도 설정, 사건 진입, 상세 전투 로그, 랜덤 시드 재현, 저장 내보내기/가져오기. 격리된 테스트 모드 우선.
- P2: 살해 전후 성장, 숙련도 5단계와 합성, 무기/공방별 성능, 보스/정예, 경제 검증. 측정 후 수치 변경 제안.
- P3: 카드 가독성, 효과 설명, 보관함 검색/필터/프리셋, 튜토리얼, 반복 연출 및 모바일 조작.
- P4: 전투 계산과 렌더링 분리, 명시적 공격 대상 전달, 2장 기능 모듈화, 자동 테스트. 필요한 부분부터 점진적으로.
- P5: 3장 신규 콘텐츠. 앞 단계에서 핵심 진행과 회귀 테스트가 안정되면 착수.
완료 조건: 재현 가능한 검증 결과, 기존 저장 호환성, 소유자 승인. 일정은 실제 테스트 결과로 산정한다.
