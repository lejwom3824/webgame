# 테스트 계획
현재 자동 테스트 실행 결과는 없다. 아래는 검증할 계획이다.
## 기본
- index.html 브라우저 실행, 콘솔 오류 확인, 모든 JS 구문 검사, python3 tools/bundle.py 실행 및 단일 HTML 확인.
- 가능하면 Playwright 등 브라우저 자동화로 새 게임/튜토리얼/전투/보상/지도/상점/저장/재시작 스모크 테스트. 환경 미지원 시 명시.
## 회귀
- 1장 시작~보스~2장 진입~2장 종료, 정상/패배/도망 경로.
- 단일/다중 적, 대상 변경, 턴 종료, 상태이상, 동료, 궁극기, 카드 합성, 무기 교체, 보관함, 보상 중복 방지.
- 제압/살해, 첫 살해 경험치, 숙련도 단계 및 합성 잠금, 지속 피해 처치, 레벨 경계.
- 세계선 최대 10개(맨 위 자동 저장 + 직접 저장 5칸), 세계선 가득 참, 저장 실패, 사망 시 막에 들어가기 전으로 되돌림, 세계선 삭제 두 번 확인, 이전 저장 마이그레이션, 전투 중 나가기.
- 2장 사건/공방/호감도/동료/상점/주식/지역 이동.
- 모바일 및 데스크톱 화면, 터치/키보드.
## 밸런스
고정 시드별 승률, 턴 수, 받은 피해, 회복, 실링, 카드 획득, 레벨/숙련도를 기록. 살해 시점과 무기/공방별 비교. 표본 수와 조건을 함께 기록하며 자동 플레이 결과는 실제 재미와 구분한다.
## 발견 기록
심각도, 커밋, 재현 절차, 기대/실제 결과, 로그, 수정 여부, 회귀 결과.
