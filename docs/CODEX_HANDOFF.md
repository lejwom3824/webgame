# Codex 인수인계 — 첫 작업
AGENTS.md 및 나머지 docs 문서를 읽고 현재 브랜치의 실제 코드와 비교한다. 기획 원문이 필요하면 소유자에게 요청한다.
## 첫 작업: P0 안정성 감사
1. 기준 커밋과 실행 환경을 기록하고 index.html 및 번들 실행을 검증한다. JS 구문 및 콘솔 오류 확인.
2. 1~2장 주요 진행 경로를 가능한 범위에서 테스트한다. 기존 훈련장 및 2장 건너뛰기 활용.
3. 우선 조사 후보: js/18-save-menu.js의 gmSave 저장 성공 여부와 토스트 불일치, js/15-ch2.js mateVisit의 조기 return(의도 확인 전 복구 금지), js/14-combat-ext.js의 C.E 임시 변경과 비동기 복구.
4. 재현된 치명적 버그만 최소 수정하고 회귀 테스트를 추가한다. 미재현 후보는 보고한다. 저장 실패 시 성공 메시지 금지.
5. 테스트 환경 및 기존 훈련장 기능을 조사하고 P1 구현 계획을 제시한다. 이번 작업에서 대규모 리팩토링/밸런스 변경/3장 제작은 하지 않는다.
